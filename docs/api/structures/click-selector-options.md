# ClickSelectorOptions Object

* `pierce` boolean (optional) - Search nested open/closed author shadow roots (default: `true`).
* `scrollIntoView` boolean (optional) - Scroll into view before clicking (default: `true`).
* `button` string (optional) - `left`, `middle`, `right`, `back`, or `forward` (default: `left`).
* `clickCount` Integer (optional) - Default: `1`.
* `modifiers` Integer (optional) - Alt=1, Ctrl=2, Meta=4, Shift=8 (default: `0`).
