## 2026-11-03：原生虚拟光标与批量输入（.4）

新增 `setVirtualCursorEnabled`、`setVirtualCursorImage`、`setVirtualCursorFrameRate`、`dispatchInputSequence`。Windows 原生 UI 光标与页面截图隔离；支持独立阻断真实指针/键盘、限帧、鼠标键盘统一 atMs 时间线、有界焦点确认、取消及失败清理。完整参数、实测和未覆盖硬件边界见 [Agent 自动化](./Agent自动化.md)。本版本同时包含 clickSelector 修复；不新增页面自动化标识，不承诺行为无法识别。

## 2026-11-04：原生网站信息与 NativePanel（Windows .5）

状态：**编译与验收通过**。Windows x64 发行版本为 [`45.0.0-cloudbypass.5`](https://github.com/ChengHoward/edist/releases/tag/v45.0.0-cloudbypass.5)；原生浮层 42 项与既有功能 46 项回归合计 **88/88** 通过。Linux x64 仍为已有 `.2`。完整接口、schema、事件、源码入口与验收边界见 [原生浮层](./原生浮层.md)。

新增网站信息与原生控件面板七入口及 `action`、`dismissed`、`closed` 事件；Windows x64 首版不新增 WebContents 或网页渲染器。网站信息使用已提交文档的 SSL/TLS/证书，权限检查仅表示当前预授权，网站设置动作交宿主处理；面板开关不改变既有 Agent 输入控制。独立输入命中区域与持续绘制租约三个可选接口未增加。

位置：`lib/browser/api/native-panel.ts`、`web-contents.ts`；`shell/browser/api/electron_api_native_panel.*`、`electron_api_web_contents.*`；`shell/browser/ui/views/native_panel.*`；模块注册、构建列表及配套 API 类型。最终发布与实测结果待编译验收完成后补齐。

## 2026-11-04：原生界面与菜单定制（Windows .6）

2026-11-04 Windows x64 发行版本为 [`45.0.0-cloudbypass.6`](https://github.com/ChengHoward/edist/releases/tag/v45.0.0-cloudbypass.6)，本地镜像已提供，安装验证及附件见该版本发布记录。Linux x64 仍为已有 `.2`，本次没有 Linux 或 macOS `.6` 包；上方 `.5` 为历史记录。

NativePanel 新增整行条目、独立图标按钮、按钮样式、状态颜色、留白、文字省略与高亮、行内链接及选中态，并优化滚动条。Menu 新增单次弹出外观、行内分段按钮和标签、`control-action` 与 `refresh()`，保留原生菜单生命周期及键盘操作，不使用 NativePanel。菜单正文、图标、勾选和单选的浅色、深色与悬停样式已一并调整。

网站信息使用 Chromium 语言资源；证书查看器改为复用 Chromium 原版 WebUI、证书树和导出逻辑。证书窗口单独增加一个隔离的 WebContents，不运行 Node 或宿主 preload；其他原生面板和菜单不增加网页渲染器。方法、截图和本地验收范围见 [原生界面定制实现与测试](./原生界面定制实现与测试.md)。
