# Electron / Chromium 定制变更简述

| 日期 | 简述 | 补丁 / 位置 |
|------|------|-------------|
| 2026-09-11 | `ses.fetch` / `net.fetch`：自定义请求头保序；新增可选 `headerOrder` | Electron：`lib/browser/api/net-fetch.ts`、`session.ts`、`docs/api/session.md` / `net.md`、`electron.d.ts` |

| 2026-08-05 | `dispatchMouseEvent` 补齐 CDP 选配参数：`timestamp` / `pointerType` / `force` / `tangentialPressure` / `tiltX` / `tiltY` / `twist` | Electron：`electron_api_web_contents.cc`、`electron.d.ts`、文档与 spec |
| 2026-07-22 | `setUserAgent({ hideChrome })`：隐藏网页主世界 `window.chrome`（可运行时切换） | Chromium：`feat_hide_chrome_in_renderer_preferences.patch`；Electron：`user_agent_options.*`、`electron_browser_context.*`、`electron_render_frame_observer.cc` |
| 2026-07-21 | `setUserAgent` 支持 `platform` + `userAgentMetadata`（Sec-CH-UA-\* / `navigator.userAgentData`） | Chromium：`feat_navigator_platform_override_in_renderer_preferences.patch`；Electron：`user_agent_options.*` 等 |
| 2026-07-21 | `webContents.dispatchMouseEvent`：无 debugger 实现 CDP `Input.dispatchMouseEvent` 同等效果 | Electron：`electron_api_web_contents.cc` 等 |
| 2026-07-21 | `session`/`webContents.setUserAgent` 实用对齐 CDP：浏览器侧强制改 UA 头 + NavigationEntry 继承 + session 广播 | Electron 源码：`shell/browser/net/user_agent_url_loader_throttle.*` 等 |
| 2026-07-21 | 跨域 OOPIF 继承 `setUserAgent`：remote 主框时仍启用 UA 覆盖 | `patches/chromium/fix_allow_ua_override_when_main_frame_is_remote.patch` |
