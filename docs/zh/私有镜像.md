# Electron 私有镜像服务

本地目录：仓库旁 `mirror/`  
对外域名：`https://electron.cloudbypass.com`

业务侧 yarn/npm 配置与 URL 约定见 [定制Electron功能说明.md §7.2](./定制Electron功能说明.md#72-私有-npm--二进制镜像)。

## 本机启动

```powershell
cd <repo>/mirror
.\run.ps1 -Publish       # 已发布过可跳过
.\run.ps1 -SetupTunnel   # 首次：登录 Cloudflare + 绑定域名
.\run.ps1                # HTTP(8787) + Tunnel
.\run.ps1 -LocalOnly     # 仅本机
```

## 业务项目速查

### `.npmrc`

```ini
registry=https://registry.npmjs.org/
electron_mirror=https://electron.cloudbypass.com/
electron_custom_dir=v{{ version }}
electron_use_remote_checksums=1
```

### 安装

```bash
yarn add electron@41.0.0-cloudbypass.1 --registry https://electron.cloudbypass.com/npm/
```

详细说明见 `../mirror/README.md`。
