# Electron 私有镜像服务

本地目录：仓库旁 `mirror/`

对外域名：`https://mirror.cloudbypass.com/electron`

业务侧 yarn/npm 配置与 URL 约定见 [定制Electron功能说明.md §7.2](./定制Electron功能说明.md#72-私有-npm--二进制镜像)。编译、发布与升版本见 [定制开发编译与更新.md](./定制开发编译与更新.md)。

## 本机启动

```powershell
cd <repo>/mirror
.\run.ps1 -Publish       # 已发布过可跳过
.\run.ps1 -SetupTunnel   # 首次：登录 Cloudflare + 绑定域名
.\run.ps1                # HTTP(8787) + Tunnel
.\run.ps1 -LocalOnly     # 仅本机
```

## 业务项目速查

### `.npmrc`

```ini
registry=https://registry.npmjs.org/
electron_mirror=https://mirror.cloudbypass.com/electron/
electron_custom_dir=v{{ version }}
electron_use_remote_checksums=1
```

### 安装

2026-11-04 Windows x64 发行版本为 [`45.0.0-cloudbypass.6`](https://github.com/ChengHoward/edist/releases/tag/v45.0.0-cloudbypass.6)，本地镜像已提供，实际安装后的运行检查通过；安装验证及附件见该版本发布记录。下方为 Windows 安装示例，Linux x64 仍使用已有 `45.0.0-cloudbypass.2`。

```bash
yarn add electron@45.0.0-cloudbypass.6 --registry https://mirror.cloudbypass.com/electron/npm/
```

Linux x64 仍使用已有 `45.0.0-cloudbypass.2`，本次不提供 `.6` Linux 包，也不能从 Windows 的原生面板或菜单能力推断 Linux 支持：

```bash
yarn add electron@45.0.0-cloudbypass.2 --registry https://mirror.cloudbypass.com/electron/npm/
```

详细说明见 `D:\electron\mirror\README.md`。`.5` 历史接口与验收见 [原生浮层](./原生浮层.md)，`.6` 的 NativePanel 样式、Menu 行内控件和原版证书查看器见 [原生界面定制实现与测试](./原生界面定制实现与测试.md)。证书窗口单独增加一个隔离的 WebContents，其他原生面板和菜单不增加网页渲染器。

当前镜像以 `mirror/config.json` 和实际平台产物为准：`https://mirror.cloudbypass.com/electron`，npm registry 为该地址加 `/npm/`。Windows 与 Linux 的可用版本须分别核对，不能仅依赖全局 latest 标签。
